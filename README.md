# 🎨 My First Portfolio

Welcome to **My First Portfolio**, a beginner-friendly HTML project designed to showcase my journey into front-end development. This project emphasizes semantic structure, accessibility, and clean navigation.

## 📁 Project Structure

This portfolio consists of multiple pages, starting with:

- `index.html` — the homepage introducing the project and its purpose.
- `tweets.html` — a secondary page linked via navigation (not shown here).

## 🧠 Purpose

This project was created to:

- Practice semantic HTML5 elements (`<header>`, `<main>`, `<article>`, `<aside>`, `<footer>`)
- Build a consistent and accessible layout
- Explore Git workflows and version control
- Incrementally improve design and structure as I learn

## 🌐 Features

- **Responsive meta setup** for mobile-friendly viewing
- **Semantic headings** (`<h1>` to `<h3>`) to organize content
- **Accessible navigation** with clear links to other pages
- **External branding** via ALX logo and link
- **Placeholder aside** for future comment thread integration
- **Footer with GitHub attribution**
